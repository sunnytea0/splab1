# Pinout сенсорної підсистеми

## STM32C031C6

| Компонент | Сигнал | STM32 pin | Інтерфейс | Напруга |
|---|---|---|---|---|
| MPU6050 | SDA | PC14 | I2C1 SDA | 3.3 V |
| MPU6050 | SCL | PA9 | I2C1 SCL | 3.3 V |
| MPU6050 | VCC | 3V3 | Живлення | 3.3 V |
| MPU6050 | GND | GND | Земля | 0 V |
| Потенціометр | SIG | PA0 | ADC1 | 0–3.3 V |
| Кнопка | SIG | PB0 | GPIO Input | 3.3 V |
| UART | TX | PA2 | USART2 TX | 3.3 V |
| UART | RX | PA3 | USART2 RX | 3.3 V |

## MPU6050

I2C-адреса пристрою:

```text
0x68
```

Регістр ідентифікації:

```text
WHO_AM_I = 0x75
```

Очікуване значення:

```text
0x68
```

## Параметри інтерфейсів

### I2C

- периферія STM32: `I2C1`;
- SDA: `PC14`;
- SCL: `PA9`;
- адреса MPU6050: `0x68`;
- логічний рівень: `3.3 V`.

### ADC

- периферія: `ADC1`;
- вхід потенціометра: `PA0`;
- діапазон значень 12-бітного ADC: `0–4095`.

### GPIO

- кнопка підключена до `PB0`;
- режим: цифровий вхід.

### UART

- периферія: `USART2`;
- TX: `PA2`;
- RX: `PA3`;
- швидкість: `115200 baud`.

## Логічний аналізатор

Для перевірки I2C у Wokwi використовується логічний аналізатор:

| Канал аналізатора | Сигнал | STM32 pin |
|---|---|---|
| D0 | SDA | PC14 |
| D1 | SCL | PA9 |

Результат захоплення зберігається у:

```text
docs/captures/i2c_mpu6050.vcd
```
