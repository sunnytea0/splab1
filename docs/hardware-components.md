# Hardware Components

Проєкт: система моніторингу положення та керування пристроєм на базі STM32.

Для реалізації проєкту використовуються три компоненти з різними інтерфейсами: I2C, ADC та GPIO. Для діагностики та виведення інформації використовується UART.

## 1. MPU-6050

**Призначення:**  
MPU-6050 використовується для визначення руху та нахилу пристрою.

**Інтерфейс:** I2C

**I2C адреса:** 0x68

**Підключення:**
- VCC -> 3.3V
- GND -> GND
- SDA -> PC14 (I2C1_SDA)
- SCL -> PA9 (I2C1_SCL)

**Функція у проєкті:**  
Отримання інформації про рух та орієнтацію пристрою.

**Перевірка:**  
Наявність MPU-6050 на шині I2C перевіряється функцією:

```c
HAL_I2C_IsDeviceReady(&hi2c1, 0x68 << 1, 3, 100);
```

У симуляції Wokwi датчик успішно визначається за адресою 0x68.

---

## 2. Potentiometer

**Призначення:**  
Потенціометр використовується як аналогове джерело сигналу.

**Інтерфейс:** ADC

**Підключення:**
- VCC -> 3.3V
- GND -> GND
- SIG -> PA0 (ADC1_IN0)

**Параметри ADC:**
- ADC: ADC1
- Channel: ADC1_IN0
- Resolution: 12 bit
- Діапазон цифрових значень: 0-4095

**Функція у проєкті:**  
Задання користувачем порогового значення або чутливості системи.

**Перевірка:**  
При зміні положення потенціометра значення ADC змінюється. У Wokwi було отримано, зокрема, значення 2214 та 4095.

---

## 3. Push Button

**Призначення:**  
Кнопка використовується для керування станом або режимом роботи системи.

**Інтерфейс:** GPIO

**Підключення:**
- Signal -> PB0
- GND -> GND

**Режим GPIO:** Input

**Функція у проєкті:**  
Кнопка може використовуватися для перемикання режиму роботи або скидання стану системи.

**Перевірка:**  
Стан кнопки зчитується функцією:

```c
HAL_GPIO_ReadPin(GPIOB, GPIO_PIN_0);
```

При натисканні кнопки значення BUTTON у UART Logger змінюється.

---

## 4. USART2

**Призначення:**  
USART2 використовується для діагностики системи та виведення інформації у Serial Monitor Wokwi.

**Інтерфейс:** UART

**Параметри:**
- Baud rate: 115200
- Data bits: 8
- Stop bits: 1
- Parity: None
- Mode: TX/RX

**Підключення:**
- PA2 -> USART2_TX -> Serial Monitor RX
- PA3 -> USART2_RX -> Serial Monitor TX

**Функція у проєкті:**  
Через UART виводяться значення ADC, стан кнопки та статус MPU-6050.

Приклад:

```text
ADC = 4095 | BUTTON = 1 | MPU6050 = OK
```

## Підсумок

У проєкті використовуються компоненти з трьома різними інтерфейсами:

- MPU-6050 -> I2C
- Potentiometer -> ADC
- Push Button -> GPIO

USART2 використовується як додатковий інтерфейс для діагностики та виведення результатів.
