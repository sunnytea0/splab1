# Задачі продукту (ЛР3)

Числові дедлайни в PRD відсутні, тому для ЛР3 вони **додані тут** (припущення команди;
внеси їх і в `docs/PRD.md`, щоб вердикт «виконана / не виконана» мав з чим порівнюватись).

| Задача | FR | Тип | Період / подія | Дедлайн (припущення) | Де в коді |
|---|---|---|---|---|---|
| imu | FR-01, 02, 03, 05 | періодична | 20 мс (S1), 10 мс (S2, S3) | запізнення ≤ 5 мс, 0 пропущених | `task_imu` |
| adc | FR-04, 05 | періодична | 100 мс | запізнення ≤ 20 мс | `task_adc` |
| report | FR-08, 09, 10 | періодична | 1 с (S1, S2), 200 мс (S3) | запізнення ≤ 50 мс | `task_report` |
| button | FR-06, 07 | подія (EXTI0) | довільна | реакція ≤ 50 мс | `task_button` + ISR |
| cmd | — | подія (байт UART) | довільна | 0 втрачених байтів | `task_cmd` |
| longop | — | довга, блокувальна | 100 мс кожні 500 мс (S3) | емуляція кадру камери / стирання сектора SPI-flash | `task_long` |

Службові піни: PA6 = IMU, PA7 = longop, PA8 = реакція на кнопку; PB0 (кнопка), PC14/PA9 (I²C).

Таймінги Wokwi — **симульовані**: достовірні порядок подій, співвідношення S3/S1, пам'ять;
недостовірні абсолютні часи шин і реальної периферії.

## Вердикт за виміряним (S3, найгірший сценарій)
| Задача | Вимога | Виміряно | Статус |
|---|---|---|---|
| imu | запізнення ≤ 5 мс, 0 пропущених | 116,7 мс, 629 пропущених | не виконана в S3 (виконана в S1: 47 мкс, 0) |
| adc | ≤ 20 мс | 22,4 мс | не виконана (ледь) |
| report | ≤ 50 мс | 8,9 мс | виконана |
| button | ≤ 50 мс | 99,2 мс max (медіана ≈ 100 мкс) | не виконана під longop |
| cmd | 0 втрачених байтів | RX overruns = 0 (потік не тестований) | потребує тесту |
